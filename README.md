# 言の葉日文課

自己讀日文用的課程網站，從五十音一路到 N1，例句大多取自動畫、輕小說和歌單裡的歌。介面是繁體中文。

## 有什麼

- **152 課**，分成 10 個階段：入門、基礎、進階、中級、動漫實戰、歌詞、輕小說、熟練、作品精讀、型月世界
- **單字大全**：572 個單字，24 個主題。每個字都有讀音、詞類、程度、什麼時候用、兩句例句和相關的詞，可以照主題、詞類、程度或五十音找
- **歌單**：每首歌的歌名讀法和裡面用到的文法（只有歌名，沒有放歌詞）
- **出處索引**：例句出自哪部作品
- **單字卡**：課程單字、歌單單字和單字大全都能抽
- **假名練習**、全站搜尋、振假名和翻譯開關、深色模式、朗讀

## 怎麼開

不用安裝任何東西，在資料夾裡開一個靜態伺服器就好：

```
python -m http.server 8000
```

然後打開 <http://localhost:8000>。學習進度存在瀏覽器的 localStorage。

## 檔案

```
index.html        頁面骨架
css/site.css      樣式
js/core.js        課程格式解析、資料登記
js/app.js         路由和各頁面
js/data/          課程內容（s0 入門 … s9 型月世界）
js/songs/         歌單（用到才載入）
js/dict/          單字大全（用到才載入）
tools/check.js    檢查課程資料的小程式，在瀏覽器主控台跑
```

### 單字大全的格式

每個單字一行，用 `|` 分欄：

```
單字|讀音|詞類|程度|意思|什麼時候用|例句=翻譯§例句=翻譯|相關詞、相關詞|課程id
```

例句裡的漢字用 `漢字[かな]` 標讀音。
